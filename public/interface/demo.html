🌐 Demostración de Activación del Widget

Portal de Pruebas Web OESVICA

Esta página simula cualquier sitio web externo (HTML, WordPress, PHP, Drupal, Intranet, etc.) donde se desee integrar el asistente virtual OESVICA.

✓ Activación Exitosa: Observa en la esquina inferior derecha el botón flotante circular azul del chatbot. Al hacer clic, se abre automáticamente la ventana de atención al trabajador sin errores de CORS ni bloqueos de seguridad.

Opción 1: Etiqueta Simple de 1 Línea (Recomendada)

Pega esta única línea justo antes del cierre de </body> en cualquier página web:

<!-- Widget Chatbot OESVICA -->
<script src="SERVER_URL/widget.js" async></script>

Opción 2: Snippet Asíncrono Personalizable

Para mayor compatibilidad con WordPress, Google Tag Manager o si deseas cambiar la posición (ej: izquierda) o el color del tema:

<!-- Snippet Asíncrono Chatbot OESVICA -->
<script type="text/javascript">
  (function(d, t) {
    var v = d.createElement(t), s = d.getElementsByTagName(t)[0];
    v.onload = function() {
      window.oesvicaChat.load({
        serverUrl: 'SERVER_URL',
        title: 'Atención al Trabajador OESVICA',
        position: 'right', // 'right' o 'left'
        themeColor: '#2563eb'
      });
    };
    v.src = 'SERVER_URL/widget.js';
    v.type = 'text/javascript';
    v.async = true;
    s.parentNode.insertBefore(v, s);
  })(document, 'script');
</script>
